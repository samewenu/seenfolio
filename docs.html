01 — JavaScript SDK

Recommended · 5 min

A single <script> tag. Works on any site — custom, Webflow, Squarespace, Wix. Best for non-technical operators who paste one tag into their site's <head>.

1

Copy your snippet

Settings → API keys. Each workspace has a unique sf_live_… prefix.

<!-- in <head>, before the closing tag -->
<script src="https://cdn.seenfolio.com/v1/sdk.js"
        data-workspace="sf_live_8h2k…7q1d"
        defer></script>
2

Paste into your site's <head>

Most platforms have a "custom code" or "header tag" setting. We've published copy-paste guides for the top 12 platforms.

SDK is 12.8 KB gzipped and defer-loaded. Never blocks render. CI budget enforced.
3

Verify in your dashboard

Settings → Integration flips to "Connected" within 30 seconds of your first page view.

If your site uses strict CSP, we auto-detect it and generate the directive you need. See the CSP fix card in your dashboard.

02 — WordPress plugin

5 min · best for WP

Server-side via the WP REST API. Modifies content with proper meta-field support. Survives theme switches.

1

Install from the plugin directory

Search "Seenfolio" in Plugins → Add New. Or grab the latest zip:

https://cdn.seenfolio.com/plugins/wp/latest.zip
2

Authorize with your workspace key

In Settings → Seenfolio inside WP, paste your key. We round-trip-verify it.

3

Choose auto-publish or staged-review

Default is staged review: every optimization sits in a 24h preview. Flip to auto-publish per page or globally.

Gutenberg and Classic Editor both supported. Inline styles preserved. Custom blocks work via filters.

03 — Cloudflare Worker proxy

10 min · advanced

Edge rewriting. Content is patched at the CDN before the browser ever sees it — best for sites needing perfect server-side SEO + GEO. Requires Cloudflare DNS.

1

Add the Seenfolio Worker as a route

Cloudflare dashboard: Workers & Pages → Add Service → Connect to existing Worker.

# wrangler.toml
name = "seenfolio-edge"
main = "https://workers.seenfolio.com/v1/edge.js"
route = "yourdomain.com/*"
[vars]
SEENFOLIO_WORKSPACE = "sf_live_8h2k…7q1d"
2

Trigger the first content sync

The Worker pulls pre-computed patches from our edge KV. Hit "Warm KV" in Settings → Integration after your first staged patch.

Worker CPU budget: under 10ms per request. Origin never called synchronously.

04 — Direct CI / Git

15 min · static sites

For Next.js, Astro, SvelteKit, Nuxt, Eleventy, Hugo, Jekyll — anything Git-deployed. We open PRs with patches, run your tests, trigger rebuild on merge.

1

Install the Seenfolio GitHub App

Grant write access to the repos you want optimized. We only touch MDX, Markdown, JSON content, and SEO meta fields.

https://github.com/apps/seenfolio
2

Add the rebuild webhook

If your host uses a deploy webhook (Vercel, Netlify, Cloudflare Pages), paste it into Settings → Integration.

SEENFOLIO_REBUILD_WEBHOOK="https://api.vercel.com/v1/integrations/deploy/prj_xxx/abc"
3

Configure your PR style

Choose batch frequency: every optimization, daily, or weekly. Default is weekly batched PRs. Each PR includes rationale + score delta.

If your CI runs Lighthouse on PRs, we use it as a safety net — patches that regress CWV get flagged.

Your first seven days

what to expect

A timeline of what Sage does in week one. No two sites are identical, but the cadence is consistent.

D1

Site audit + first recommendations

Full ingest. SEO + GEO + CWV scoring on every page. 5 highest-impact recommendations surfaced. One small optimization staged.

D2

Attribution baseline

Your first 24 hours of events build the attribution baseline. By end of day 2 the dashboard shows live revenue, customers, visitors with channel breakdown.

D3

First content patch goes live

24h staging window elapses. Optimization goes live. Outcome measurement starts (we re-check the affected metric in 7 days).

D5

Content gaps surfaced

We identify high-volume queries you don't rank for. Brand voice calibrated from existing content. A draft sits in your Inbox.

D7

First weekly digest

Every Monday at 8am local: a digest of everything Sage did, what worked, what didn't, what's planned. Pause anything in one click.
